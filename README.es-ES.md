# Bionic Reading EPUB Converter

![WakaTime](https://waka.mpassarello.de/api/badge/MaxP/interval:any/project:bionic-reading-epub-converter?label=Project%20time)

Esta aplicación web le permite convertir un archivo EPUB a un archivo EPUB con Lectura Biónica (Bionic Reading). La aplicación procesa el texto dentro del EPUB para mejorar la experiencia de lectura aplicando los principios de la Lectura Biónica.

## Características Principales

- **Conversión de EPUB a Lectura Biónica**: Suba su archivo EPUB y la aplicación procesará el texto para añadir las mejoras de Lectura Biónica.
- **Privacidad del Usuario**: Todo el procesamiento se realiza localmente en su dispositivo. Su archivo EPUB nunca sale de su ordenador, garantizando su privacidad y la seguridad de sus datos.
- **Facilidad de Uso**: Interfaz sencilla e intuitiva para subir su archivo y descargar la versión convertida.

## Notas Importantes

1. **Conserve el Archivo Original**: Guarde siempre una copia de su archivo EPUB original. Aunque el proceso de conversión pretende mantener la integridad de su archivo, no hay garantía de éxito para todos los archivos EPUB debido a las variaciones en el formato y la estructura.
2. **Sin Garantía de Éxito**: La aplicación hace todo lo posible para convertir su archivo con precisión, pero debido a la naturaleza diversa de los archivos EPUB, es posible que algunos no se conviertan perfectamente o que no se conviertan en absoluto.
3. **Procesamiento Local**: Todo el procesamiento de archivos ocurre en su ordenador, lo que significa que sus datos no se suben a ningún servidor. Esto mejora la privacidad, pero también significa que el rendimiento de la aplicación depende de las capacidades de su dispositivo.

## Primeros Pasos

Para utilizar la aplicación, visite el [sitio de GitHub Pages de Bionic Reading EPUB Converter](https://pxammaxp.github.io/bionic-reading-epub-converter-webapp/).

## Uso

1. **Subir un archivo EPUB**: Haga clic en el botón de subida y seleccione un archivo EPUB de su ordenador.
2. **Procesamiento**: La aplicación procesará el archivo EPUB y aplicará las mejoras de Lectura Biónica al texto.
3. **Descargar el Archivo Convertido**: Una vez finalizado el procesamiento, descargue el archivo EPUB convertido en su ordenador.
